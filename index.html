    方法說明
    1. 讀取資料：略過含缺值的列；整欄都是數字的視為數值特徵，其餘視為類別。
    2. One-hot：類別依字母排序，丟掉第一個作為基準類別（drop first），避免與截距共線。
    3. 切分：以固定 seed（mulberry32 + Fisher–Yates 洗牌）打亂後，依比例切出測試集，筆數無條件進位。
    4. 特徵選擇（只用訓練集）：先剔除與前面欄位線性相依的特徵，再以下列方法產生 k = 1…p 的特徵子集：
      • Forward SFS：從只有截距開始，每一步加入讓訓練集 RSS 最小的特徵。
      • RFE（Backward）：從全部特徵開始，每次刪掉標準化係數絕對值最小的特徵。
      • Lasso：X、y 標準化後沿 L1 正則化路徑（λ 由大到小），依特徵第一次出現非零係數的順序排名。
      • ElasticNet：同 Lasso，但懲罰項為 L1 與 L2 各半（l1_ratio = 0.5）。
      • Exhaustive：每個 k 列舉所有組合，取訓練集 RSS 最小者（特徵超過 15 個時停用）。
    5. 評估：每個子集以 OLS（含截距）在訓練集擬合，在測試集計算 RMSE、R²、MAE；test RMSE 最低者為最佳模型。
    6. 統計推論：係數表、Adjusted R² 與 F 檢定都是訓練集 OLS 的結果（同 statsmodels）；VIF = 1 / (1 − R²ⱼ)，R²ⱼ 為該特徵對其餘特徵回歸的 R²。

    註：最佳模型是依測試集挑出的，嚴謹的做法是另留驗證集或使用交叉驗證。

    CRISP-DM 流程

    1. 商業理解確立要預測的目標（target）與成功標準：測試集 RMSE 越低越好。
    2. 資料理解讀取 CSV，檢視筆數、欄位型別與缺值（見「資料設定」）。
    3. 資料準備略過缺值列、類別欄 one-hot（drop first），以固定 seed 切分訓練集與測試集。
    4. 建模以五種方法挑出 k = 1…p 的特徵子集，各自在訓練集以 OLS 擬合。
    5. 評估比較測試集 RMSE、R²、MAE，並檢查係數顯著性、VIF 與測試集殘差。
    6. 部署以純前端靜態網頁發布（可部署到 GitHub Pages），用即時預測器套用模型。
